# Memory Labs downloads

Memory Labs helps digitize and organize old photos and home videos.

The desktop app is being tested. **No public installer is available yet.**

- [Download page](https://ianwatts22.github.io/memory-labs-releases/)
- [Approved releases](https://github.com/ianwatts22/memory-labs-releases/releases)

Apple-silicon macOS is the first supported target. This repository contains only the download
page and approved installers/update assets, not the private application source. Your originals
stay intact; AI processing can send derived images to cloud services.
